# 🐄 Qurbani Animal Marketplace

## 📌 Project Purpose

Qurbani Animal Marketplace is a modern web application where users can browse, explore, and book animals (cows, goats, etc.) for Qurbani. The platform focuses on providing a smooth, secure, and user-friendly experience for buying livestock online.

---

## 🌐 Live URL

👉 https://qurbanirhat-assignment-8.vercel.app

---

## ✨ Key Features

* 🐄 Browse different animals with detailed information
* 🔍 View top breeds and featured listings
* 📝 Book animals using a simple booking form
* 🔐 User authentication (Email & Google login)
* 🎨 Modern UI with animations
* ⚡ Fast performance using Next.js
* 📱 Fully responsive design (mobile, tablet, desktop)

---

## 🚀 Technologies Used

* **Next.js** – React framework for production
* **React** – UI library
* **Tailwind CSS** – Styling
* **@heroui/react** – UI components
* **react-hook-form** – Form handling
* **react-hot-toast** – Toast notifications
* **Animate.css** – Animations
* **React Icons** – Icons
* **Authentication Library** (auth-client)
